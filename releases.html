What's new

This is the first release macOS opens without the "unidentified developer" warning — no right-clicking, no trip to System Settings. Penkeep is now signed with an Apple Developer ID and notarized by Apple.

  • Touch ID unlocks your encrypted notes. The switch in Settings → Encryption has been greyed out since the day it appeared, because macOS refuses to put biometric protection on an application it cannot identify. Turn it on and opening an encrypted note asks for your fingerprint instead of your passphrase. Apple Watch and your Mac's password both work as fallbacks. A note you have already opened this session reopens without asking again — Penkeep holds the passphrase for thirty minutes, and Lock Now (⌘L) ends that whenever you want. The passphrase never leaves your Mac and is never synced to iCloud. macOS only.
  • macOS will ask once more for permission to read your folders. Being signed makes this a new application identity, so the access you granted earlier builds does not carry across. Allow it once and that is the end of it — future updates will not re-ask. Nothing you have saved is affected.
  • Decrypting a note no longer leaves its passphrase behind. Turning a note back into plain text — or deleting it — used to leave the saved passphrase in your Keychain indefinitely, filed under a note that no longer existed.
  • A folder could disappear from the sidebar without you removing it. If Penkeep could not open one at startup it quietly dropped it, permanently — and it could not tell "deleted" apart from "macOS has not granted permission yet". The list now only shrinks when you remove a folder yourself.
  • Fixed: a file that could be dragged into a folder but never back out, a wiki-link to an unreadable file offering to create it, buttons on plain text files that did not apply to them, and an About dialog that now shows the version and links to penkeep.com.

What was new

Encryption now goes both ways. Right-click an encrypted note and choose Decrypt note, and it becomes an ordinary .md again, with its comment threads restored to the files they came from. Until now the menu offered Encrypt note with no way back.

  • Export without opening. Export… is on the file-tree right-click menu, so you can export a note you are not looking at. A note with unsaved changes exports what is on screen, not the older version on disk.
  • Folders and tabs drag into the order you want, and a folder you collapse stays collapsed after a restart.
  • Tags stay inside their own folder. Saving a note used to put its tags into whichever folder's list happened to be showing, so tags drifted between folders depending on what you had touched. Switching folders no longer blanks the tags on the note you are reading, either.
  • Pinning a note no longer takes its close button away. It keeps its full name and normal size too, marked by a small coloured corner instead of a pushpin.
  • Fixed: Encrypt note appearing on images and archives it could not act on, .markdown notes that refused to encrypt, a locked note exporting the wrong document, exports arriving full of [c1] markers, and emd decrypt dropping comment threads without saying so.

What was new

Alongside Light and Dark there are now eight more themes — Sepia and Linen for warm paper, Snow for a cool low-glare grey, Nord, Graphite, True Black for OLED screens, Forest, and Ember.

  • A picker that previews the real thing. Settings → Appearance lists every theme; arrow up and down and the whole app changes as you go, so you are judging the editor itself rather than a thumbnail.
  • Every theme brings its own accent, and a Match chip hands the choice back to the theme — pick a swatch or a custom colour and that wins instead. Nord and Ember carry their own syntax-highlighting colours.
  • Follow system appearance is a single toggle, and it now notices when you change your Mac's appearance mid-session instead of waiting for the next launch.
  • Preferences no longer disagree between windows. Changing a setting in one window and then anything in another silently put the first one back, taking your recent-files list with it. Windows now write only what changed, and tell each other.
  • Compare before you choose. When a file has changed on disk and you have unsaved edits, both prompts now lead with a side-by-side comparison.
  • Fixed: a flash of white when a window opens (noticeable on the darker themes), code that no longer stood out from the page, unreadable labels on accent-coloured buttons, text selection stuck at teal instead of following your accent, a word count that skipped documents you had not typed in and lost a word at every paragraph, and dates that did not read day-first — including in the files saved beside your notes.

The three most recent versions are kept here. Older builds are retired — upgrade rather than pin to a version that no longer receives fixes.
